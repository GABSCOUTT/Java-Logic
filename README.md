☕ Java Logic — Estudos de Lógica de Programação

Repositório dedicado aos meus estudos e à prática de lógica de programação utilizando Java.

O objetivo deste projeto é desenvolver minha capacidade de resolver problemas por meio da programação, colocando em prática os fundamentos da linguagem Java e evoluindo gradualmente para conceitos mais avançados.

🎯 Objetivos do Projeto

Desenvolver o raciocínio lógico e computacional.

Aprender e praticar os fundamentos da linguagem Java.

Resolver exercícios práticos de programação.

Compreender estruturas de controle e manipulação de dados.

Desenvolver pequenos projetos para consolidar o aprendizado.

Construir uma base sólida para o desenvolvimento de software.

💻 Como executar os exercícios

Clone este repositório:

git clone https://github.com/GABSCOUTT/Java-Logic.git

Abra o projeto no IntelliJ IDEA ou em outra IDE compatível com Java.

Localize o exercício que deseja executar dentro da pasta src.

Execute o método main da classe correspondente.
